# Comment Style

## 方針

- このリポジトリでは、日本語コメントを積極的に書く。

## コメント対象

- 関数の目的
- 入出力
- 主な処理内容
- 処理のまとまり
- 定数の意図
- DOM 依存、React Fiber 依存、正規表現、遅延処理、例外処理の理由

## 書き方

- 「何をしているか」だけでなく、「なぜその実装にしているか」も書く。
- コードを読めば分かる最低限ではなく、後から意図を追える量まで書く。
- 単なる逐語訳ではなく、壊れやすい前提や設計上の理由が残るようにする。

## 期待する粒度

- 関数には、目的・入出力・主要処理を説明するコメントを付ける。
- 複数行の重要な処理ブロックには、まとまりの説明を付ける。
- 定数には、値そのものではなく用途や背景を補足する。
